# Check if input urbanicity is valid

Checks if a supplied urbanicity value is valid (must be "urban",
"rural", or "suburban").

## Usage

``` r
check_urbanicity(urbanicity)
```

## Arguments

- urbanicity:

  Single urbanicity value (must be one of these: "urban", "rural",
  "suburban")

## Value

Returns invisible TRUE if checks pass. Side effect of stopping
calculation if any check fails.
