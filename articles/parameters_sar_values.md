## Parameters

Parameters are specified in YAML files:
[`params.yaml`](https://wipfir97.github.io/RFDose/articles/inst/extdata/params.yaml)
for all parameters except SAR values, and a SAR file for the SAR values
([`sar_goliat_average.yaml`](https://wipfir97.github.io/RFDose/articles/inst/extdata/sar_goliat_average.yaml)
by default, see [GOLIAT SAR values](#goliat-sar-values)). Parameters are
obtained from measurements, dosimetric simulations, and literature- more
detailed descriptions of each parameter, including units and data
sources, will be included in Jalilian et al. (manuscript in
preparation).

## GOLIAT SAR values

The GOLIAT SAR files (`inst/extdata/sar_goliat_*.yaml`) contain SAR
values from GOLIAT dosimetric simulations, used instead of the ETAIN SAR
values
([`sar_etain.yaml`](https://wipfir97.github.io/RFDose/articles/inst/extdata/sar_etain.yaml)).
There is one file per phantom (Duke, Ella, Eartha, Thelonious) and one
with the average of the four phantoms (`sar_goliat_average.yaml`), which
is the default. The files are generated by
[`data-raw/source-sar-goliat/sar_goliat.R`](https://wipfir97.github.io/RFDose/articles/data-raw/source-sar-goliat/sar_goliat.R)
from the GOLIAT results file (`Final_Data_All_2026_LAST.xlsx`, not
included in this repository), which is read by
[`data-raw/source-sar-goliat/reading_raw_goliat_sar.R`](https://wipfir97.github.io/RFDose/articles/data-raw/source-sar-goliat/reading_raw_goliat_sar.R).
